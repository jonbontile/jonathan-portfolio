# Instructions for Claude Code

## Intent
Build and maintain Jonathan Bontile, CPA's portfolio for freelance clients and international employers. Follow `PROJECT_BRIEF.md`, `CLAUDE_CODE_IMPLEMENTATION_PLAN.md`, `CONTENT_STRATEGY.md`, `DESIGN_SYSTEM.md`, `VISUAL_DESIGN_BRIEF.md` and `CLAUDE_CODE_DESIGN_IMPLEMENTATION.md`.

## Content rules
- Never fabricate credentials, experience, client names, testimonials, metrics, outcomes, tools or availability.
- Treat missing facts as pending verification. Omit from public pages until supplied and approved.
- Case studies must be anonymized, evidence-based and approved. Do not expose confidential or identifying information.
- Exact brand orange is pending. Do not guess a HEX or label a temporary token official.
- Use genuine approved headshot/resume assets only; never generate a substitute identity or resume.

## Engineering and operational rules
- Inspect repository and preserve established conventions before editing; do not assume it is empty.
- Target Astro, TypeScript, Tailwind and Markdown-first content, subject to architecture verification. Cloudflare Workers static assets only if compatible with the actual setup.
- Use semantic HTML, keyboard access, visible focus, clear errors, responsive layouts and reduced-motion support.
- Contact processing must be server-side, validated, abuse-resistant and privacy-conscious. Keep secrets out of client bundles.
- Preserve Google Workspace MX. Do not edit DNS or configure email before reviewing records and sender verification. Resend only after sender/domain verification and mail-flow review.
- Do not deploy, publish, change DNS/GitHub, or overwrite unrelated files without direct authorization.

## Work protocol
1. Inspect and report repository, architecture, assets and status.
2. Separate verified facts from assumptions and list unknowns.
3. Make focused changes that fit the project.
4. Explain changes and unresolved gates.
5. Run checks only when requested and report exact results.
